## Install

Install it with a mod manager for Hexium, such as [Gale](https://github.com/Kesomannen/gale), which
also installs the Nucleus mod loader it needs, and start the game from there. The main menu then shows
"Map Cell Tracker" and its version under the game's, in the bottom-left corner, so you can tell it's
loaded. Explore a bit, and open the map.

The mod also works without a mod manager, with the game's own launch option: see the
[install steps on GitHub]({{repo}}/blob/{{tag}}/README.md#install).

## Settings and your found cells

The mod keeps its settings (`primordialis_qol.toml`), its log and the cells you've found in the game
folder, not in the mod manager's profile, so they stay when you update the mod. To open the game folder:
in Steam, right-click Primordialis, then **Manage** → **Browse local files**. The
[settings]({{repo}}/blob/{{tag}}/README.md#settings) are all on by default, and changes apply right away,
even while the game is running.
